# OCS 처방 도우미

흐름 프로그램에 지정된 **오늘 검사**를 OCS 오더 입력창에 대신 넣어 주는 작은 프로그램입니다. 의사 PC(윈도우)에서 AutoHotkey v2로 실행합니다.

- **F9** — OCS에 열려 있는 환자의 검사 처방을 넣습니다.
- **F10** — 명단 모드입니다. 오늘 처방을 넣을 환자를 예약 순서대로 OCS 외래 명단에서 찾아 넣고, **환자마다 멈춥니다**. 오더를 확인하고 서명한 뒤 F9를 누르면 다음 환자로 넘어갑니다.
- 다 넣으면 흐름 프로그램 검사실 화면의 **[처방 전]이 '처방 완료'로** 바뀝니다(버튼을 직접 누른 것과 같은 기록).
- **서명(F2)은 절대 하지 않습니다.** OCS에서 D/C인 **Delete 키도 쓰지 않습니다.**

> 병원 전산 프로그램을 자동으로 조작하는 도구입니다. 전산팀(의료정보팀)의 승인을 받은 뒤 쓰시고, 처음에는 한 PC에서 검사 한두 개로 시작하세요.

---

## 1. 준비 (한 번만)

### 1-1. 흐름 프로그램에 OCS 입력법 등록

흐름 프로그램 → **설정 → 검사실 · 검사** → 검사의 **[자세히]** → 아래쪽 **OCS 처방 입력법**.

| 칸 | 적는 것 |
|---|---|
| 양측 | 양안 검사일 때 OCS 입력창에 칠 검색어와 후보 목록에서 ↓를 누를 횟수 |
| 편측 | 한쪽 눈(우안·좌안) 검사일 때의 검색어와 ↓ 횟수 |

- 예: VF 양측 = `Visual field test`, ↓ 1번 / VF 편측 = `Visual field test`, ↓ 0번
- ↓ 0번은 검색어를 친 뒤 바로 Enter를 누른다는 뜻입니다.
- **OCT**처럼 세부 종류의 눈 위치 그룹이 'M,D OCT'와 'OCTA'로 나뉜 검사는 **OCT 양측·편측, OCTA 양측·편측** 네 칸이 나옵니다. Macular와 Disc를 같이 해도 OCT 처방은 하나만 넣습니다.
- 비워 둔 칸은 도우미가 넣지 않고 **'직접 입력'** 으로 알려 줍니다. 한 검사의 처방(예: OCT와 OCTA) 중 하나라도 비어 있으면 그 검사는 통째로 직접 입력입니다.
- OCS에 처방하지 않는 검사는 검사 줄의 **[처방 없음]** 칩을 켜 두세요. 도우미도 건너뜁니다.
- 저장을 누르면 모든 PC에 반영됩니다.

같은 검색어를 치면 후보 순서가 항상 같다는 전제로 동작합니다. 새 검사를 등록하면 OCS에서 한 번 직접 확인하세요.

### 1-2. 도우미 설치 (의사 PC)

1. https://www.autohotkey.com 에서 **v2.0**을 받아 설치합니다(v1.1이 아닌 **v2**).
2. 업데이트 zip 안의 `ocs-helper` 폴더를 의사 PC에 복사합니다(예: `문서\OCS도우미`).
3. `ophflow-helper.ahk`를 더블클릭하면 작업 표시줄 오른쪽 아래에 초록색 **H** 아이콘이 생깁니다.
   - 설정 파일 `ophflow-helper.ini`와 기록 파일 `ophflow-helper.log`가 같은 폴더에 생깁니다.
   - PC를 켤 때마다 자동으로 실행하려면 `Win + R` → `shell:startup` 폴더에 `ophflow-helper.ahk`의 바로가기를 넣으세요.

### 1-3. 등록 (설정 창)

트레이 아이콘(H)을 더블클릭하면 설정 창이 열립니다. 항목을 고르고 **[선택 항목 등록]**.

| 항목 | 하는 방법 |
|---|---|
| 흐름 프로그램 서버 주소 | 브라우저 주소창에 쓰는 주소를 그대로 적습니다(예: `http://192.168.0.10:3000`, 이 PC가 서버 PC면 `http://localhost:3000`). 적으면 바로 연결을 시험합니다 |
| OCS 창 | OCS 진료 화면 위에 마우스를 올리고 **F8** |
| 환자번호 앞쪽 / 뒤쪽 | OCS 화면의 환자번호(예: 16318174) 숫자 **바로 왼쪽**과 **바로 오른쪽**에 마우스를 올리고 F8. 도우미가 이 사이를 드래그해서 복사합니다 |
| 처방 입력창 | 오더발행의 처방 입력창 안에 마우스를 올리고 F8 |
| 외래 명단 여는 버튼 | (명단 모드) OCS 외래 명단을 여는 버튼 |
| 명단 환자검색 칸 | (명단 모드) 외래 명단 왼쪽 아래 '환자정보(번호,이름)' 입력칸 |
| 명단 첫 줄 | (명단 모드) 번호로 검색했을 때 나오는 첫 줄의 환자이름 |

- F8을 누를 때 클릭은 하지 않아도 됩니다. 취소는 Esc.
- OCS는 **평소 쓰는 크기(최대화)** 로 두고 등록하세요. 창 크기나 화면 배치(패널 크기)가 바뀌면 다시 등록해야 합니다.
- 등록한 뒤 **[환자번호 읽기 시험]** 과 **[흐름 연결 시험]** 으로 확인하세요.

흐름 프로그램 화면은 켜 두지 않아도 됩니다. 도우미가 서버에 직접 물어봅니다.

## 2. 연습 모드로 먼저 확인하기

OCS를 건드리지 않고 서버와 주고받는 것까지 확인할 수 있습니다.

1. 트레이 아이콘 우클릭 → **연습 모드 (메모장)**
2. 메모장을 열고 그 안에서 **F9**
3. 환자번호를 물으면 오늘 흐름 명단에 있는 번호를 넣습니다.
4. 메모장에 `[처방 1] 입력창 클릭 → 'Visual field test' 입력 → ↓ 1번 → Enter` 같은 줄이 적힙니다. 실제 OCS에서는 이 순서대로 누릅니다.
5. 마지막에 흐름 프로그램에도 처방 완료로 표시할지 묻습니다. **가상 환자로 연습할 때만 '예'** 를 누르세요.

메모장에서 **F10**을 누르면 명단 모드도 연습할 수 있습니다.

## 3. 사용법

### F9 — 지금 열린 환자

1. OCS에서 환자를 열고 오더발행 화면이 보이게 둡니다.
2. **F9**
3. 도우미가 환자번호를 읽고 → 서버에서 오늘 검사를 받아 → 확인 창을 띄웁니다.
   > 윤지아 (6100259) — VF 양측, OCT 양측 … 넣을까요?
4. **[예]** 를 누르면 환자번호를 한 번 더 확인한 뒤 한 줄씩 넣습니다. **넣는 동안 마우스·키보드를 만지지 마세요. 멈추려면 Esc.**
5. 오더 목록을 확인하고 **직접 서명**합니다.

진료 중에 검사를 추가하면 그 검사는 [처방 전]으로 돌아갑니다. F9를 다시 누르면 새로 생긴 것만 넣습니다.

### F10 — 명단 모드 (외래 명단에서 환자를 찾아서)

1. OCS 메인 화면에서 **F10** → 교수와 '접수한 환자만'을 고르고 [시작] → 오른쪽 위에 명단 창이 뜹니다.
2. **F9** → 첫 환자의 확인 창 → [예] → OCS 외래 명단에서 그 환자를 찾아 열고, 환자번호가 같은지 확인한 뒤 처방을 넣고 **멈춥니다**.
3. 오더를 확인하고 **서명**한 뒤 **F9** → 다음 환자.
4. 환자를 못 찾거나 멈추면 명단 창에 이유가 나옵니다. F9로 다시 하거나 **[이 환자 건너뛰기]**.
5. 다 끝나면 **[명단 모드 끝내기]**(또는 F10).

명단 창의 [다음 환자] 버튼을 눌러도 F9와 같습니다. 확인 창이 번거로우면 설정 파일에서 `BatchConfirm=0`으로 바꿀 수 있습니다(그러면 F9를 누르는 것이 확인이 됩니다).

**환자를 찾는 방법:** 도우미는 OCS 명단의 글자를 읽지 못해서, 명단을 연 뒤 '환자정보(번호,이름)' 칸에 번호를 넣고 Enter → 첫 줄 더블클릭 순서로 엽니다. 병원 OCS에서 이 순서가 맞지 않으면 설정 파일의 `[OpenPatient] Steps`를 고치면 됩니다(아래 5번). 어떤 순서든 **연 뒤에 환자번호를 다시 읽어서 같을 때만** 처방을 넣습니다.

## 4. 안전장치

- 서명(F2)과 Delete(D/C)는 누르지 않습니다. 입력창을 지우는 키(Ctrl+A, Delete)도 쓰지 않습니다.
- 넣기 전에 OCS 화면의 환자번호를 **두 번** 읽어서 흐름 프로그램 환자와 같은지 확인합니다(확인 창 전, 입력 직전).
- 한 줄 넣을 때마다 OCS 창이 앞에 있는지 확인합니다. 팝업이 뜨거나 다른 창이 앞에 오면 즉시 멈춥니다.
- OCS 창 크기가 등록할 때와 다르면(팝업이 앞에 있거나 창 크기가 바뀜) 시작하지 않습니다.
- 입력창을 누른 뒤 글자 커서가 입력창 근처에 없으면 멈춥니다(OCS가 커서 위치를 알려주는 경우만).
- 언제든 **Esc**로 멈출 수 있습니다. 멈추면 몇 건을 넣었는지 알려 주고, **처방 줄을 모두 넣은 검사만** 처방 완료로 표시합니다.
  - OCT와 OCTA처럼 한 검사에 처방이 둘인데 하나만 넣고 멈췄다면, 도우미가 기억해 두었다가 같은 환자에서 다시 F9를 누를 때 **남은 것만** 넣습니다(도우미를 끄면 이 기억은 지워지니, 그 전에 마무리하세요).
- 작업 기록은 `ophflow-helper.log`에 남습니다(환자번호와 처방 이름만, 이름은 남기지 않음).

## 5. 병원에서 처음 시험할 때 확인할 것

연습 모드가 잘 되면, OCS에서 **검사 하나만 등록한 상태로** 한 환자에 시험하세요. 아래가 병원 OCS와 맞지 않으면 설정 파일(`트레이 아이콘 → 설정 파일 열기`)을 고치고 **설정 다시 불러오기**를 누르세요.

| 확인할 것 | 맞지 않을 때 |
|---|---|
| 검색어를 치면 후보 목록이 바로 뜨나요? | Enter를 쳐야 뜬다면 `EnterToSearch=1` |
| 후보 목록이 뜨기 전에 ↓가 눌리나요? | `WaitAfterType`을 늘립니다(예: 1500) |
| 처방을 고른 뒤 다음 줄이 너무 빨리 시작되나요? | `WaitAfterEnter`를 늘립니다 |
| 처방을 고른 뒤 입력창이 비워지나요? | 비워지지 않으면 알려 주세요(지우는 키를 일부러 쓰지 않습니다) |
| 처방을 고르면 작은 창(수량·부위 등)이 뜨나요? | 도우미가 멈춥니다. 알려 주시면 그 창 처리 순서를 추가하겠습니다 |
| 검색어의 영문이 한글로 바뀌어 입력되나요? | `TypeMode=paste` 또는 `text` |
| '커서가 입력창에 들어가지 않은 것 같아요'가 계속 뜨나요? | 위치를 다시 등록해 보고, 그래도 뜨면 `CaretCheck=0` |
| F9·F10이 OCS의 다른 기능과 겹치나요? | `HotkeyRun`, `HotkeyBatch`를 바꿉니다(예: `^F9` = Ctrl+F9) |
| (명단 모드) 번호를 검색하면 그 환자 한 줄만 남나요? | `Steps`의 순서를 병원 OCS에 맞게 고칩니다 |
| (명단 모드) 명단 버튼을 누르면 명단이 닫히나요(이미 열려 있을 때)? | `Steps`에서 `click:ListButton|wait:1500|`를 빼고, 명단을 열어 둔 채 진행 |

## 6. 설정 파일 (`ophflow-helper.ini`)

| 이름 | 기본값 | 뜻 |
|---|---|---|
| HotkeyRun | F9 | 현재 환자 / 명단 모드의 다음 환자 |
| HotkeyBatch | F10 | 명단 모드 시작·끝 |
| TypeMode | keys | 검색어 입력 방식: keys, text, paste |
| WaitAfterClick | 300 | 입력창을 누른 뒤 기다림(밀리초) |
| WaitAfterType | 800 | 검색어를 친 뒤 후보 목록을 기다림 |
| EnterToSearch | 0 | 1이면 검색어 뒤에 Enter를 먼저 누름 |
| WaitAfterSearch | 800 | 위 Enter 뒤 기다림 |
| DownDelay | 150 | ↓ 사이 간격 |
| WaitAfterEnter | 1200 | 처방을 고른 뒤 다음 처방까지 기다림 |
| BatchConfirm | 1 | 명단 모드에서 환자마다 확인 창 |
| CaretCheck | 1 | 입력창 커서 확인 |
| SizeTolerance | 40 | OCS 창 크기 허용 오차(픽셀) |
| [Server] Url | (없음) | 흐름 프로그램 서버 주소 |

`[OpenPatient] Steps`는 명단 모드에서 환자를 여는 순서입니다. `|`로 나눕니다.

- `click:위치이름`, `dclick:위치이름`(더블클릭) — 위치이름: `ListButton`, `ListSearch`, `ListFirstRow`
- `type:{ID}` — 환자번호 입력
- `key:{Enter}`, `key:^a` — 키 입력(AutoHotkey 표기). `{Delete}`와 `{F2}`는 쓸 수 없습니다.
- `wait:1500` — 1.5초 기다림

기본값:
```
click:ListButton|wait:1500|click:ListSearch|key:^a|type:{ID}|key:{Enter}|wait:1500|dclick:ListFirstRow|wait:3000
```

## 7. 문제 해결

| 메시지 | 할 일 |
|---|---|
| 흐름 프로그램 서버에 연결하지 못했어요 | 서버 PC가 켜져 있는지, 설정 창의 서버 주소가 브라우저 주소와 같은지 확인 |
| 서버가 도우미 요청을 모르는 것 같아요 | 서버를 이 기능이 들어간 버전으로 업데이트하고 서버를 껐다 켜기 |
| 오늘 흐름 프로그램 명단에 없는 환자예요 | 흐름 프로그램 오늘 명단에 그 환자가 있는지, 환자번호가 같은지 확인 |
| OCS 창 크기가 등록할 때와 달라요 | 팝업을 닫고 OCS를 최대화. 계속 다르면 창과 위치 다시 등록 |
| 환자번호를 읽지 못했어요 | '환자번호 앞쪽·뒤쪽'을 숫자 양 끝에 맞춰 다시 등록 → [환자번호 읽기 시험] |
| 단축키가 안 먹어요 | OCS 창이 앞에 있어야 동작합니다. 'OCS 창'을 등록했는지 확인 |

## 8. 참고: 서버와 주고받는 방식

도우미는 흐름 프로그램 서버의 아래 주소를 씁니다(서버 쪽 코드: `scripts/ocs-api.js`, 규칙: `src/core/ocs.js`). 답은 탭으로 나눈 글이고 첫 줄이 `OPHFLOW1 <종류>`입니다.

| 주소 | 하는 일 |
|---|---|
| `GET /api/ocs/ping` | 연결 확인 (오늘 날짜, 명단 인원, 처방 넣을 환자 수) |
| `GET /api/ocs/list` | 오늘 처방을 넣을 환자 (예약 순) |
| `GET /api/ocs/patient?id=환자번호` | 그 환자에게 넣을 처방 |
| `POST /api/ocs/done` (본문 `id=…` `tests=vf,oct`) | 넣은 검사를 처방 완료로 표시 |

메인 화면에서 날짜를 직접 정했으면 그 날짜를 오늘로 씁니다.
