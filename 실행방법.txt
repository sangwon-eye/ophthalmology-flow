안과 환자 흐름 - 로컬 테스트

1. https://nodejs.org/en/download 에서 Node.js LTS를 설치합니다 (22.12 이상).
2. 압축을 풀고 package.json이 있는 폴더를 엽니다.
3. 탐색기 주소창에 powershell 을 입력하고 Enter를 누릅니다.
4. 아래 두 줄을 순서대로 실행합니다.

npm.cmd install
npm.cmd run dev

브라우저가 자동으로 열립니다. 열리지 않으면 http://localhost:5173 으로 접속하세요.
실행 중에는 PowerShell 창을 열어 두세요. 종료는 Ctrl+C입니다.
다음 실행부터는 npm.cmd run dev만 입력하면 됩니다.

첫 화면에서 접수/관리 화면에 들어가 샘플 환자를 불러와 테스트할 수 있습니다.
설정 화면은 비밀번호 없이 바로 열립니다.

원본의 window.storage 대신 브라우저 localStorage를 사용하는 테스트용입니다.
데이터는 같은 브라우저·주소에서만 유지됩니다. 여러 컴퓨터 사이에 공유되지 않습니다.
실제 공유 운영에는 별도의 서버/공유 저장소가 필요합니다.
