안과 환자 흐름 - 내부망 공유 사용 방법
==========================================

[누가 무엇을 읽나요]
  직원      : 이 파일을 읽지 않아도 됩니다. 관리자 > [역할별 안내문]을 인쇄해 자리마다 붙이세요
              (흐름 그림 1장 + 자리별 1장: 하는 일 5줄 + 이럴 땐). 처음에는 리허설로 직접 해 보는 것이 가장 빠릅니다.
  관리 담당 : 이 파일은 서버 설치·백업·문제 해결 참고서입니다. 필요한 번호만 찾아 보세요.
  흐름·설정 정리(무엇을 설정에서 바꿀 수 있는지) : 업무흐름정리.md

[구조]
  컴퓨터 한 대를 "서버 PC"로 정합니다. 앱과 데이터는 서버 PC에만 있습니다.
  다른 컴퓨터(접수, 검사실, 진료실, 처치실 등)는 아무것도 설치하지 않고
  브라우저(크롬 또는 엣지) 주소창에 서버 PC 주소만 입력하면 됩니다.

  서버 PC 고르는 법: 근무 시간 내내 켜져 있는 컴퓨터로 정하세요.
  서버 PC가 꺼지면 다른 컴퓨터에서도 사용할 수 없습니다.


------------------------------------------
1. 서버 PC 처음 설정 (한 번만)
------------------------------------------
 (1) Node.js 설치
     https://nodejs.org 에서 LTS 버전(22.12 이상)을 받아 설치합니다.
     서버 PC에 인터넷이 안 되면, 인터넷 되는 PC에서 설치 파일(.msi)을 받아
     USB나 공유폴더로 옮겨서 설치하세요.
     관리자 권한이 없어 설치가 안 되면 (압축 파일 버전):
       Node.js 압축 파일(node-v…-win-x64.zip)을 풀고 → 폴더 이름을 node 로 바꾼 뒤 →
       이 프로그램 폴더 안에 넣으세요 (node\node.exe 가 있어야 합니다).
       서버를 켜고 끄는 .bat 파일들이 자동으로 이 node 폴더를 사용합니다.

 (2) 이 폴더를 서버 PC의 내 컴퓨터(예: C:\안과흐름)에 복사합니다.
     ※ 공유폴더(네트워크 드라이브) 안에서 실행하지 마세요. 느리고 오류가 날 수 있습니다.

 (3) 서버켜기_창없이.bat 을 더블클릭합니다.
     아래처럼 주소가 나오면 성공입니다 (창은 10초 뒤 저절로 닫히고 서버는 계속 켜져 있습니다).
        다른 컴퓨터에서 접속: http://192.168.0.15:3000   ← 예시입니다
     이 주소를 메모해두세요.

 (4) 처음 실행할 때 "Windows 보안 경고(방화벽)" 창이 뜨면
     "개인 네트워크"(병원 네트워크면 "도메인 네트워크"도)에 체크하고 [액세스 허용]을 누릅니다.
     관리자 권한이 없어 허용하지 못하면 전산실에
     "3000번 포트(TCP) 내부망 접속 허용"을 요청하세요.


------------------------------------------
2. 매일 사용 - 창 없이 켜기 (추천)
------------------------------------------
  서버 PC : 서버켜기_창없이.bat 더블클릭
            → 접속 주소가 잠깐 나오고 10초 뒤 창이 저절로 닫힙니다.
            → 서버는 화면에 창 없이 계속 켜져 있어서, 실수로 닫을 일이 없습니다.
            → 혹시 서버가 멈춰도 5초 뒤 저절로 다시 켜집니다.
  다른 PC : 브라우저에서 http://서버PC주소:3000 접속
            (즐겨찾기나 바탕화면 바로가기로 만들어두면 편합니다)

  서버 관련 파일 (모두 서버 PC에서 더블클릭)
    서버켜기_창없이.bat  창 없이 켜기 (평소에 사용)
    서버끄기.bat         끄기 (Y 를 눌러 한 번 더 확인합니다)
    서버상태확인.bat     켜져 있는지, 접속 주소가 무엇인지 보기
    서버시작.bat         창이 떠 있는 방식으로 켜기 (오류 확인용)
    백업복구.bat         백업에서 되살리기 (서버를 끈 뒤에 실행, 4번 참고)

  글씨 크기: 각 화면 오른쪽 위(메인 화면은 제목 아래, 환자용 화면은 오른쪽 아래)의 "글씨" 칸에서 고릅니다.
    - 자동: 창을 좁게 쓰면 글씨와 칸이 함께 작아집니다 (기본값)
    - 70% ~ 150%: 원하는 크기로 고정
    컴퓨터마다 따로 기억합니다. 한 컴퓨터에서 바꿔도 다른 컴퓨터는 그대로입니다.
    글씨를 줄여도 환자 이름·대기 번호·주요 버튼·메인 화면 버튼 제목은 읽기 좋은 크기로 유지되고,
    80% 이하에서는 설명 문구를 숨겨 명단이 더 많이 보이게 합니다.

  ※ 창 없이 켜진 상태에서는 기록이 data\server-log.txt 에 남습니다.
  ※ 서버 PC를 재부팅하면 서버도 꺼집니다. 아래처럼 자동 시작을 설정해두세요.

  서버 PC가 켜질 때 자동으로 서버도 켜지게 하려면:
    Windows키 + R → shell:startup 입력 → 열린 폴더에
    서버켜기_창없이.bat 의 "바로 가기"를 넣어두세요 (파일 자체가 아니라 바로 가기).
    (서버켜기_창없이.bat 에서 마우스 오른쪽 → 바로 가기 만들기 → 만든 바로 가기를 그 폴더로 옮기기)

  화면 맨 위에 빨간 줄로 "서버 PC에 연결되지 않았습니다"가 나오면
  서버 PC에서 서버상태확인.bat 을 실행해보고, 꺼져 있으면 서버켜기_창없이.bat 을 실행하세요.
  연결되지 않은 동안 입력한 내용은 저장되지 않습니다.
  그 밖의 화면 맨 위 알림 띠:
    - 빨간 "저장 실패": 방금 누른 내용이 서버에 저장되지 않았습니다. 화면이 저장된 내용으로 돌아가니 확인하고 다시 입력한 뒤 [확인].
    - 빨간 "서버의 ○○ 파일이 손상되어…": 그 항목만 저장·불러오기를 멈춘 상태입니다 (다른 항목은 그대로 됩니다).
      서버 PC에서 백업복구.bat 으로 되살립니다 (4번).
    - 노란 "서버가 손상된 ○○ 파일을 …으로 되돌렸습니다": 정전 등으로 깨진 파일을 서버가 저절로 되살렸습니다.
      되돌린 시점 뒤에 입력한 내용이 빠졌는지 확인하고 [확인]을 누르세요 (컴퓨터마다 한 번).
  화면 오류: 화면을 그리다 오류가 나면 흰 화면 대신 "화면을 그리는 중 오류가 났습니다" 안내가 나옵니다.
    [다시 시도] 또는 [메인 화면으로]를 누르세요. 저장된 내용은 그대로이고, 오류 내용은 서버 기록에 남습니다.
    (사람이 없는 환자용 화면 등을 위해 30초 뒤 저절로 다시 시도합니다)
  마지막 화면 기억: 컴퓨터마다 마지막으로 연 화면(진료실은 고른 교수님까지)을 기억해서,
    새로고침(F5)하거나 컴퓨터를 다시 켜도 그 화면으로 바로 열립니다. 메인 화면으로 나오면 메인 화면부터 열립니다.
    설정 화면은 비밀번호 때문에 기억하지 않습니다.

3. 코드를 수정했을 때 (업데이트)
------------------------------------------
  (1) 서버 PC의 src 폴더 안 파일을 수정합니다. 화면마다 파일이 나뉘어 있습니다:
        src\views\ (StationView=시력방·검사실, ConsultView=진료실, TreatView=처치실, AdminView=관리자,
                   SettingsView=설정, BoardView=환자용 화면·QR 접수, RoleSelect=메인 화면)
        src\ui\common.jsx (여러 화면 공용 카드·버튼), src\core\ (진료 흐름 규칙·저장소), src\App.jsx (전체 연결)
  (2) 업데이트.bat 을 더블클릭합니다. (처음 한 번은 인터넷 연결이 필요합니다)
  (3) 끝나면 각 컴퓨터 화면 위에 "새 버전이 있습니다" 알림이 뜹니다.
      환자용 화면·QR 접수는 알림 없이 1분 안에 저절로 새로고침합니다 (화면을 누르는 사람이 있으면 30초 동안 손대지 않을 때까지 기다림).
      진료실 앞 모니터는 새로고침 뒤 크롬이 띵동 소리를 막으니, 오른쪽 아래 작은 노란 종이 보이면 화면을 한 번 눌러 주세요.
      화면 맨 아래(메인 화면·직원 화면)의 "버전 09-28 14:05"(화면 파일을 만든 시각)로 새 버전인지 확인할 수 있습니다.
      [새로고침]을 누르면 적용됩니다. 서버를 다시 켤 필요는 없습니다.

  ※ 환자가 많은 시간에는 업데이트를 피하세요 (몇 초 동안 화면이 안 열릴 수 있습니다).
  ※ 업데이트 중 오류가 나면 서버는 이전 버전 그대로 계속 동작합니다.
  ※ server.js 를 수정한 경우에만 서버끄기.bat → 서버켜기_창없이.bat 순서로 다시 켜세요.
  ※ 다른 PC에서 수정했다면 수정한 파일(src 폴더)을 서버 PC 폴더에 덮어쓴 뒤 업데이트.bat 을 실행하세요.
  ※ 자동 테스트(개발용 PC): tests\README.md 참고. 테스트는 따로 된 데이터로 돌아 실제 data 폴더를 건드리지 않습니다.
  ※ 자동 코드 검사(개발용 PC): npm run lint  (쓰지 않는 코드·실수를 찾아 줌. 서버·병원 PC에는 필요 없음)

4. 데이터와 백업
------------------------------------------
  데이터 폴더 : data\keys  (서버 PC에만 있습니다. 항목별로 파일이 나뉘어 있습니다)
                이전 시력 기록은 환자가 계속 쌓이므로 data\keys\measure-history 폴더 안에
                환자번호 끝 두 자리별 100개 파일(00.json ~ 99.json)로 나눠 둡니다 (예: …33 → 33.json).
                저장할 때 그 작은 파일 하나만 다시 써서, 누적 환자가 많아져도 느려지지 않습니다.
  자동 백업   : data\backups\날짜 폴더  (하루 한 번 그날 첫 저장 전 상태, 최근 30일 보관)
  시간별 사본 : data\backups-hourly\날짜 폴더  (환자 명단·FU 지정을 1시간마다, 오늘·어제만 보관)
  정전 대비   : 저장할 때마다 디스크에 확실히 기록하고, 직전 저장본(.prev)도 남깁니다.
                파일이 깨지면 서버가 직전 저장본 → 시간별 사본 → 하루 백업 순서로 저절로 되돌리고 화면에 노란 띠로 알립니다
                (깨진 파일은 지우지 않고 "…손상-날짜시각" 이름으로 남겨 둠). 되돌릴 것이 없으면 그 항목만 멈추고 덮어쓰지 않습니다.

  지난 명단 자동 보관:
    모든 컴퓨터가 실시간으로 주고받는 명단은 "어제 ~ 앞으로의 날짜"만입니다.
    그보다 지난 명단은 서버가 자동으로 월별 보관 파일(patients-archive-연-월)로 옮깁니다.
    지난 명단은 관리자 > 명단 관리 또는 전체 환자 명단에서 날짜를 고르면 볼 수 있습니다 (보기 전용).
    환자별 이전 정보(FU)와 측정 기록은 그대로 유지됩니다.

  ※ 서버설정.txt 의 BACKUP_DIR 을 적으면 하루 백업이 data\backups 대신 그 폴더에만 생깁니다 (두 곳에 함께 남지 않음).
    그 폴더에 연결되지 않는 날은 백업이 빠지므로 보통은 적지 마세요.

  복구 방법 (백업복구.bat):
    (1) 서버끄기.bat 으로 서버를 끕니다 (서버가 켜져 있으면 백업복구.bat 이 멈춥니다).
    (2) 백업복구.bat 을 실행하면 되살릴 시점이 최근 것부터 나옵니다 (시간별 사본 → 하루 백업). 번호를 고릅니다.
    (3) 무엇을 되살릴지 고릅니다: 환자 명단만 / FU 지정만 / 둘 다 (하루 백업은 "전부"도 가능 — 설정·교수 목록·이전 시력까지).
    (4) Y 를 누르면 지금 데이터를 data\keys-복구전-날짜시각 폴더에 그대로 보관한 뒤 되살립니다.
    (5) 서버켜기_창없이.bat 으로 다시 켜고 각 컴퓨터에서 F5.
    잘못 골랐으면: 서버를 끄고 keys-복구전 폴더 안의 파일을 data\keys 에 다시 복사하세요.

  폴더를 다른 서버 PC로 옮길 때는 data 폴더도 같이 복사하세요.

5. 여러 컴퓨터가 동시에 입력하면?
------------------------------------------
  두 컴퓨터가 같은 순간에 저장해도, 늦게 저장한 쪽이 최신 내용을 다시 불러와서
  자기 변경을 다시 적용합니다. 그래서 한쪽 입력이 사라지지 않습니다.
  다른 컴퓨터의 변경은 보통 1초 안에 화면에 반영됩니다.
    - 어느 컴퓨터에서 버튼을 누르면 서버 PC에 바로 저장되고, 서버 PC가 연결된 모든 화면에 "바뀌었다"고 바로 알립니다
      (환자 정보는 보내지 않고 무엇이 바뀌었는지만). 알림을 받은 화면이 서버에서 새 내용을 받아 갑니다.
    - 백신·네트워크 문제로 알림이 막혀도 각 화면이 4초마다 스스로 확인하므로 늦어도 4초 안에는 맞춰집니다.
    - 뒤에 숨겨 둔 탭(다른 탭을 보고 있을 때)은 알림 연결을 닫아 두고 4초 확인만 합니다. 다시 보면 바로 연결됩니다.
  같은 환자를 두 컴퓨터가 거의 동시에 눌러도 흐름이 깨지지 않게 서버의 최신 상태로 다시 확인합니다:
    - 같은 교수님 진료실 화면 두 곳에서 1~2초 사이에 다른 환자를 [진료 호출]하면 먼저 누른 환자만 진료 중이 되고,
      늦게 누른 화면에는 "진료 호출 안 됨 · ○○ 환자가 이미 진료 중입니다"가 나옵니다.
    - QR 접수가 먼저 됐는데 시력방에서 늦게 [접수]를 눌러도 처음 접수 시각·순서 그대로입니다.
    - 검사실 두 장비에서 같은 환자를 거의 동시에 [▶ 시작]하면(진행 중 호출 금지 검사) 먼저 누른 검사만 시작되고,
      늦게 누른 화면에는 "시작 안 됨 · ○○ 환자는 이미 VF 검사 중입니다"가 나옵니다.
    - [설명 완료]를 두 곳에서 눌러도 먼저 누른 쪽의 FU만 저장됩니다 (늦게 누른 화면: "이미 다른 곳에서 설명 완료되었습니다").
    - 다른 곳에서 막 설명 완료(귀가)한 환자에게 [처치 보내기]를 하면 처치를 넣지 않고 "처치 지정 안 됨"이 나옵니다
      (넣으면 처치실·설명 대기 어디에도 보이지 않아 처치가 빠지기 때문). 정말 처치가 필요하면 진료실 화면 아래
      '방금 완료한 환자'에서 [설명 완료 취소]를 누른 뒤 다시 보내세요.
    - 다른 곳에서 처치를 새로 보낸 환자는 [귀가]가 되지 않고 "귀가 처리 안 됨 · 처치가 새로 들어와 있습니다"가 나옵니다.
    - 처치실 [처치 완료]·진료실 [교수님 처치 완료]는 화면에 보이던 처치만 완료합니다. 그사이 새 처치가 들어왔으면
      그 처치는 남고 "새로 들어온 처치가 남아 있습니다"가 나옵니다 (하지 않은 처치가 완료로 찍히지 않게).
    - 검사 준비(FAG skin test 등)의 [시작]·[시작 취소]·[확인]과 진료실 요청 처리는 다른 곳에서 먼저 한 것을 다시 적용하거나
      지우지 않습니다 (예: 늦게 누른 [시작 취소]가 방금 한 확인을 지우지 않음).
    - [되돌리기]는 그 버튼으로 바꾼 것만 되돌립니다 (그사이 다른 검사실에서 완료한 다른 검사는 그대로).
      그사이 다른 곳에서 그 환자를 귀가 처리하는 등 다음 단계로 넘겼으면 되돌리지 않습니다.
    - "○○ 안 됨" 안내가 나오면 화면이 몇 초 안에 최신 상태로 바뀝니다. 바뀐 화면을 보고 필요하면 다시 누르세요.

6. 명단 다시 올리기
------------------------------------------
  엑셀 제목 줄: 환자명 · 환자번호 · 예약 · 초재진 · 진료의 (칸 순서는 상관없습니다).
    - 제목은 이 5가지와 글자가 정확히 같아야 합니다 (예: "예약시간", "초/재진"은 못 찾음).
      진단명·보훈 등 다른 칸이 있어도 읽지 않고 저장하지 않습니다.
    - 진료의 칸으로 교수님을 알아서 나눕니다. 한 파일에 여러 교수님 환자가 있어도 됩니다.
      "김선웅 교수", "김선웅(안과)"처럼 적혀 있어도 설정 > 교수 관리의 "김선웅"과 맞춥니다.
    - 진료의가 등록된 교수님과 맞지 않거나 비어 있는 환자는 등록하지 않고 결과 창에 빨간색으로 보여줍니다.
    - 5가지 칸 중 하나라도 없으면 파일 전체를 올리지 않고 빠진 칸을 알려줍니다. [템플릿 받기]로 양식을 받을 수 있습니다.
  같은 날짜·교수 명단을 여러 번 올려도 됩니다 (예: 1주 전에 올리고, 전날 추가 환자 포함해 다시 올리기).
  진료 날짜는 어제부터 고를 수 있습니다 (명단 업로드·환자 추가 모두). 그저께 이전은 보관된 명단이라 새로 올리지 않습니다.
  - 이미 있는 환자: 지정해둔 검사·산동·진행 상황은 그대로. 예약시간이 바뀌었으면 새 시간으로 고칩니다.
  - 새 환자: 추가합니다. 설명 완료 때 저장된 이전 정보(같은 교수님)가 있으면 자동으로 붙습니다.
  - 파일에서 빠진 환자: 자동으로 지우지 않고 목록으로 보여줍니다. 확인 후 [삭제]를 두 번 누르세요.
  - 같은 날 다른 교수 명단에도 있는 환자: 두 교수님 진료로 연결합니다 (아래 7번).

  명단 관리의 [정보 수정]으로 이름·환자번호·예약시간을 고칠 수 있습니다.
  명단 관리 카드에 이전 시력·안압이 표시되고, 이전 시력이 없으면 [이전 시력 입력] 버튼만 보여 눌러서 넣을 수 있습니다
    (안압은 비워도 됩니다). 시력실에는 입력 버튼 없이 이전 값만 표시됩니다.
    오늘 측정한 값은 다음 내원 때 자동으로 이전 값이 됩니다.
  명단 관리에서 교수님을 골라 그 교수님 명단만 볼 수 있습니다.
  오늘 날짜: 보통은 컴퓨터 날짜를 그대로 씁니다. 메인 화면의 "오늘 날짜" 칸에서 날짜를 고르고
    옆의 [모든 컴퓨터 ○월 ○일로 바꾸기]를 한 번 더 눌러야 바뀝니다 (잘못 고르면 [취소]).
    바꾸면 모든 컴퓨터가 그 날짜 명단을 보고, 화면 위에 "날짜 ○○ (직접 정함)"이 표시됩니다.
    다음 날이 되면 저절로 풀리고, [실제 날짜로 되돌리기]로 바로 풀 수도 있습니다.
    어제보다 앞 날짜는 고를 수 없습니다 (그저께 이전 명단은 서버가 월별 보관 파일로 옮겨 둡니다).
    지난 명단은 관리자 > 명단 관리나 전체 환자 명단에서 날짜를 고르면 그대로 보입니다 (보기 전용).

  지각: 직원이 [접수]를 누르면 자동으로 정하지 않습니다. 환자 카드 이름 줄의 [지각](시력·안압 접수 대기 카드는 [접수] 옆)을
    직원이 눌러 표시합니다. 시력실·검사실·진료실 어느 화면에서나 켜고 끌 수 있습니다.
    바코드 접수는 찍은 시각이 예약 + 지각 유예 시간(설정 > 기타)보다 늦으면 자동으로 지각이 됩니다.
    지각이면 제시간 환자들 뒤로 가고, 다시 누르면 원래 순서로 돌아옵니다.
    예약시간이 없는 환자(명단에 없던 환자 등)는 접수하면(직원·바코드 모두) 지각으로 맨 뒤에 섭니다.
    [지각]을 끄면 접수 시각을 예약시간처럼 써서 그 시각 순서에 들어갑니다. 나중에 예약시간을 넣어도 순서는 그대로이니
    필요하면 직원이 끌어서 옮기세요.

  오전/오후 버튼(명단 관리, 시력·안압의 접수 대기): 예약 12:00 전은 오전, 12:00부터 오후입니다.
    예약시간이 없는 환자는 오전·오후 모두에 보입니다.
  예약시간순/가나다순 버튼(명단 관리, 시력·안압, 검사실, 처치실): 컴퓨터마다 기억합니다.
    가나다순일 때도 번호는 실제 대기 순서이고, 순서 바꾸기(끌기·화살표)는 예약시간순에서만 됩니다.
  [전체 삭제]는 지금 보이는 명단(날짜 + 선택한 교수님)을 한 번에 지웁니다.
  삭제 직후 나오는 [되돌리기]로 복구할 수 있습니다.

  명단 관리에서 주황색 테두리 + "검사 미지정 · 확인 필요"로 표시된 환자는
  재진인데 오늘 검사(CR 포함)가 하나도 없는 환자입니다. 검사를 지정해주세요.

6-1. 진료실에서 되돌려 보내기 · 처방 완료 · 진찰실 번호
------------------------------------------
  진료실 [보내기] (진료 중 환자 카드, 진료 대기 목록):
    - 시력/안압 다시 : 시력·안압을 다시 측정
    - 검사실        : 누락된 검사 추가 또는 오늘 한 검사 다시
                      [세부 창] 검사(예: OCT)를 고르면 아래에 종류·단안 칸이 열립니다 (다른 검사는 오른쪽 클릭).
    - 처치실        : 처치실에서 확인 후 진료 대기로 (처치실 맨 위 "진료실 요청 확인")
      처치실에서는 [검사 추가] (예진 함께 선택 가능) / [시력/안압 다시] / [예진 추가] /
      [확인 완료 · 진료 대기로] 중에서 고릅니다. 모두 끝나면 진료 대기로 돌아갑니다.
    전달 메모를 적으면 받는 곳 환자 카드에 노란색으로 보입니다.
    확인이 끝나면 다시 그 교수님 진료 대기로 돌아옵니다.
    순서: [보내기 → 검사실]로 보낸 환자도 순서를 앞으로 당기지 않습니다. 검사실·진료실 모두 원래 예약 순서대로입니다 (공평하게).
      예) 9시30분 환자가 먼저 진료를 보고 추가 검사가 나오면, 검사실에서도 예약이 빠른 사람 다음에 검사하고,
          돌아왔을 때 9시 환자가 아직 진료 대기라면 9시 환자 다음으로 들어갑니다. 급하면 직원이 위·아래로 옮기면 됩니다.
    진료 대기 1번 보호: 검사가 늦게 끝나 예약 순서로는 진료 대기 1번이 되는 환자는 2번째로 들어갑니다
      (지금 1번 환자는 곧 들어갈 사람이라 그대로). 예약 순서로 2번째 이후면 그 자리 그대로입니다.
      진료실 화면에서 위·아래로 옮기면 진료 순서만 바뀌고 시력·검사 순서는 그대로입니다.

  검사실 [처방 전]: 전산 처방을 넣은 뒤 누르면 그 자리가 "처방 완료"로 바뀝니다 (직원 화면에만 표시).
    처방은 한 번에 넣으므로, 어느 검사실에서 눌러도 그 환자의 모든 검사실에 처방 완료로 표시됩니다.
    처방 완료 뒤 검사가 새로 추가되거나 다시 하게 되면 그 검사가 있는 검사실에
    [추가 처방 필요: 검사 이름] 버튼으로 바뀌고, 누르면 다시 처방 완료가 됩니다.
    잘못 눌렀으면 "처방 완료" 옆의 ↺ 를 누르면 처방 전으로 돌아갑니다.

  설명 대기 카드에는 "오늘 검사 OCT, WFP, 산동"처럼 오늘 마친 검사와 산동(CR 환자는 "CR")이 한 줄로 보입니다 (점안 시각·횟수는 쓰지 않음).
  처치가 있는 환자: 진료 완료 후 바로 "설명 대기"로 가고 이름 옆에 "처치 중"이 표시됩니다.
    - 교수님 처치는 설명 대기 카드의 [교수님 처치 완료], 전공의 처치는 처치실의 [처치 완료].
    - 처치가 끝나면 "처치 완료"로 바뀌고, 평소처럼 [설명 완료]를 누르면 끝납니다.
    - 진료 후에 외래 간호사가 처치를 넣을 때: 설명 대기 카드 맨 오른쪽 [처치 보내기] (진료 호출을 다시 하지 않아도 됨).
    - 처치 창은 한 줄에 2개씩 보입니다. 설정 > 처치에서 처치마다 정한 대로, 체크하면 그 칸 안에
      [눈 고르기] → [OU] [OD] [OS] 버튼 (예: YAG → OS, 처치실·설명 대기에 "YAG · OS"로 보임),
      [메모 칸] → 짧은 메모 칸이 나타납니다. (예전의 공용 "처치 메모" 칸은 없앴습니다. 다른 메모는 환자 메모에)
    - 목록에 없는 처치는 "기타 요청"에 적고 교수님/전공의를 고릅니다.
    - [산동 필요]를 켠 처치(예: YAG)를 진료 후에 보내면 산동 예정이 저절로 켜집니다.
      이미 점안한 환자는 그 점안 시각이 그대로 이어지고, 아직이면 설명 대기·처치실 카드의 [산동]으로 기록합니다.
      산동이 끝나면 처치실에 띵동과 "시간 됨 · ○○ 산동 완료" 알림이 납니다 ([처치 완료]는 막지 않음).
    - 교수님 처치와 전공의 처치가 같이 있으면, 전공의 처치는 교수님 처치를 기다리지 않고 바로 처치실에 올라옵니다
      (처치실 카드에 "교수님 처치도 남음: …"이 작게 보임). 상황에 맞게 먼저 할 것을 하면 됩니다.
    - [처치 취소]는 두 번 눌러야 취소됩니다 (한 번 누르면 "누르면 취소", 3초 안에 한 번 더).
      설명 대기에서 [처치 보내기]로 넣은 처치는 취소해도 설명 대기에 그대로 남습니다.
      "산동 필요" 처치 때문에 켜진 산동은, 아직 점안 전이면 그 처치를 취소할 때 함께 꺼집니다.
      설명 대기 순서는 그대로이고, 잘못 넣었으면 아래 알림의 [되돌리기]나 "처치 취소"로 뺍니다.
    - 처치 중에 설명을 먼저 하면: [설명 완료] → 처치실 명단에 "설명 완료 · 처치 후 귀가" 표시 →
      처치 완료 → 진찰실 카드에 [귀가] 버튼 → 누르면 명단에서 빠집니다 (2차 진료는 이때 시작).

  검사실 카드에는 할 검사 칸 줄 끝에 [+ 검사 변경]만 있습니다 (시력방은 지정된 검사 칩도 함께). 누르면 모든 검사와
    산동/CR 켜기·끄기(검사 줄 맨 끝)가 펼쳐지고, 맨 아래의 [접기]로 닫습니다.
    산동 줄은 산동·CR 예정인 환자에게만 보입니다.
    (관리자 명단 관리의 "확인 필요" 환자는 처음부터 펼쳐져 있습니다)

  검사실 화면: 할 검사는 굵은 네모 칸으로 보입니다. VF는 한 칸 안에 [▶ 시작]이 있고,
    검사 중에는 그 칸이 주황색으로 바뀌며 [종료]·[시작 취소]가 나옵니다.
    위쪽 장비 버튼(VF·OCT·WFP 등)을 눌러 장비 컴퓨터마다 자기 장비 환자만 볼 수 있습니다.
    설정 > 검사실 · 검사에서 검사마다 [0명도 표시] 칩을 켜고 끕니다.
    켠 검사는 항상 보이고, 끈 검사는 기다리는 환자가 있을 때만 보입니다. (처음에는 모두 켜져 있습니다)
    기다리는 환자가 없는(0명) 검사 칩은 흐리게 보여, 환자가 있는 검사가 바로 눈에 띕니다.
  검사실 묶음: 시력방·처치실을 뺀 모든 검사실(예: 31번방·6번방)은 한 묶음입니다.
    - 위쪽 "검사 대기" 줄 아래에 같은 묶음의 다른 검사실 대기가 방마다 한 줄씩 보입니다 (예: 31번방 화면에 "6번방 IDRA 2명").
      다른 검사실 칩은 보기만 하는 것이라 눌러도 바뀌지 않고, 기다리는 환자가 있는 검사만 보입니다.
    - 빨간 점(●): 묶음 안에서 대기 순서가 가장 빠른 환자(지금 검사 중인 환자 제외)가 기다리는 검사입니다.
      남은 검사가 여러 개면 그 칩 모두에 붙습니다. 어느 검사실이든 먼저 비는 곳에서 데려가면 됩니다.
      점에 마우스를 올리면 환자 이름과 예약시간이 보입니다.

  직원 메모: 모든 직원 화면의 환자 카드에서 이름 옆 메모 아이콘으로 적습니다
    (예: 타과 진료 다녀오심, 혈청 다녀오심, YAG 후 10:30 IOP 확인). 환자용 화면에는 나오지 않습니다.

  진료실 [설명 완료 · FU 나중에]: 너무 바빠 다음 내원 검사를 정할 수 없을 때 환자를 먼저 보냅니다.
    - 다음 내원 검사는 저장하지 않고, 관리자 > FU 지정 관리 맨 위 "FU 나중에 지정할 환자"에 올라갑니다.
    - 그 환자가 다음 명단에 올라오면 카드에 "지난 진료 FU 미지정"이 표시됩니다
      (명단 관리의 "확인 필요"에도 포함).
    - FU 지정 관리에서 [지정]하면 표시가 사라지고, 이미 올라간 다음 명단(접수 전)의 검사도 바뀝니다.
    - 교수님별로 따로 남습니다: 두 교수님이 같은 환자에게 모두 [FU 나중에]를 누르면 FU 지정 관리에 교수님마다 한 줄씩 보이고,
      한 교수님 것을 지정하면 그 교수님 줄만 사라집니다. 다음 명단의 "FU 미지정"도 그 교수님 진료 기록에만 표시됩니다.
  FU를 저장하면(진료실 설명 완료, 관리자 FU 지정 관리) 이미 올려 둔 다음 명단에도 바로 적용됩니다:
    같은 환자·같은 교수님·아직 접수 전인 기록의 검사·산동·CR·진료 전 처치가 새 FU로 바뀝니다.
    다른 교수님 명단과 2차 진료로 이어진 기록은 그대로입니다 (두 교수님 계획이 합쳐져 있어서).
  FU 지정은 평소에 명단(오늘 + 올려 둔 날짜) 환자 것만 주고받아 빠르게 동작합니다.
    관리자 > FU 지정 관리 탭을 연 동안만 전체를 받아 모든 환자를 찾아볼 수 있습니다.
  FU 지정 관리에는 교수님별로 "최근 진료" 날짜가 함께 표시됩니다.
  진료실 [설명 완료 · FU 없음 (회송)]: 회송서를 쓰고 보내는 등 다음 내원이 없는 환자. 설명 완료 창 맨 아래 [FU 나중에] 오른쪽에 있습니다.
    - FU를 잡지 않고, "FU 나중에 지정할 환자"에도 올라가지 않습니다. 그 교수님의 예전 FU 지정도 지웁니다 (같은 환자의 다른 교수님 FU는 그대로).
    - 전체 환자 명단에는 "진료 완료 · 회송"으로 보입니다. 잘못 눌렀으면 아래 알림의 [되돌리기].
  설명 완료 창(다음 내원 검사): [세부 창] 검사(예: OCT)는 고르면 바로, 다른 검사는 오른쪽 클릭(태블릿은 길게 누르기)으로 단안·프로토콜 칸이 열립니다.
  관리자 > FU 지정 관리의 [지정]·[수정] 창은 진료실 설명 완료 창과 같은 모양입니다 (다음 내원 담당, 주요 검사, [나머지 검사 보기] 안에 담당 교수 바꾸기·진료 전 처치).
    - 창 맨 아래 작은 빨간 글씨 "FU 없음 · FU 명단에서 삭제"를 두 번 누르면 그 교수님의 FU를 명단에서 지웁니다 ("FU 나중에" 환자도 같음). 같은 환자의 다른 교수님 FU는 그대로 남습니다.

  설정 > 교수 관리 "진찰실": 숫자만 적으면 "3번 진료실"로, 글자를 적으면 그대로
    환자용 화면(진료 대기 순서)에 표시됩니다.

  설정 > 검사실 · 검사 "검사 선택 창 순서": 환자 카드의 "오늘 검사" 버튼과 추가 검사,
    설명 완료, 처치실 검사 지정, FU 지정 창에 나오는 검사 순서를 바꿉니다.

6-2. 처치실의 진료 전 검사 (예: Syringing) · 시력방·처치실 이름
------------------------------------------
  설정 > 검사실 · 검사 맨 아래 "처치실 (고정)" 칸에 검사를 추가하면(예: Syringing)
    처치실 화면 맨 위 "진료 전 검사"에서 다른 검사실과 같은 카드로 진행합니다.
    - 다른 검사실 검사가 모두 끝난 뒤 처치실 대기에 뜹니다 (그 전에는 검사실 카드에 "다른 검사실 남음"으로 표시).
    - 진료 전 검사가 끝나야 진료 대기로 갑니다. 예진·처치는 지금처럼 처치실 화면 아래쪽에서 합니다.
    - 메인 화면에는 처치실 칸 하나만 있습니다.
  처치실 위쪽 요약 줄: 화면 맨 위(제목 아래)에 묶음마다 몇 명인지 칩으로 보입니다. 스크롤해도 계속 위에 붙어 있습니다.
    (결과 확인 · 진료 전 처치 · 검사 준비 · 진료 전 검사 · 진료실 요청 · 검사 지정 · 처치 대기)
    - 칩을 누르면 그 묶음으로 바로 이동합니다. 0명인 묶음은 흐리게 보입니다.
    - 초록 "● N 시간 됨": 시간이 다 돼 [확인]할 환자가 그 묶음에 있습니다.
    - 주황 "20분↑ N": 마지막 진행(접수·검사 완료·산동·처치 등) 뒤 20분 넘게 그대로인 환자가 있습니다.
      그 환자 카드는 주황 테두리와 "23분째 그대로"로 강조됩니다 (시간을 재는 중인 환자는 제외).
    - 강조 시간은 설정 > 기타 "처치실 오래 기다린 환자 강조"에서 바꿉니다 (0분이면 끔).
  진료실 위쪽 요약 줄: 교수님을 고르면 제목 아래에 설명 대기 · 진료 대기 · 진료 보류 인원이 칩으로 보입니다.
    누르면 그 묶음으로 이동하고, 0명은 흐리게 보입니다 (진료실에는 주황 강조 없음).
  시력방과 처치실도 직원 화면 이름·환자에게 보이는 이름을 설정 > 검사실 · 검사에서 바꿀 수 있습니다
    (예: 1번 시력검사실, 32번 처치실).

6-3. 설정 비밀번호 · 접속 비밀번호
------------------------------------------
  설정 > 기타 > "설정 비밀번호"에서 정하면, 모든 컴퓨터에서 설정에 들어갈 때마다 비밀번호를 묻습니다.
    - 바꾸려면 현재 비밀번호와 새 비밀번호를 넣고 [비밀번호 저장], 없애려면 [비밀번호 없애기].
    - 비밀번호는 서버 PC의 data\settings-lock.json 에 알아볼 수 없는 형태(해시)로만 저장됩니다.
  잊어버렸을 때: 서버 PC에서 설정비밀번호초기화.bat 을 더블클릭 → Y. 비밀번호가 없어지고 설정에 바로 들어갈 수 있습니다.
  접속 비밀번호 (설정 > 기타 > "접속 비밀번호"): 주소를 아는 다른 사람이 프로그램에 들어오지 못하게 합니다.
    - 정하는 순간부터 모든 컴퓨터(직원 화면·환자용 화면·QR 접수·태블릿)에서 처음 한 번 비밀번호 화면이 나옵니다.
      한 번 맞게 넣으면 그 컴퓨터(크롬)는 기억해서 다음부터 묻지 않습니다. (크롬 방문 기록·쿠키를 지우면 다시 물음)
    - 화면만 막는 것이 아니라 서버가 직접 막습니다. 주소를 알거나 코딩을 조금 알아도 비밀번호 없이는 명단을 보거나 바꿀 수 없습니다.
      (남는 틈: 병원 망 통신을 전문 도구로 엿보는 경우, 서버 PC를 직접 만지는 경우 → 서버 PC는 윈도우 로그인 비밀번호로 잠가 두세요)
    - 5번 틀리면 그 컴퓨터는 1분 동안 잠깁니다.
    - 바꾸면 다른 컴퓨터들은 몇 초 안에 비밀번호 화면으로 바뀝니다. 새 비밀번호를 한 번씩 넣어 주세요.
      환자용 화면·QR 접수 PC도 다시 넣어야 하니, 바꾸기 전에 그 PC들 위치를 알아 두세요.
    - 바꾸기·없애기에는 현재 접속 비밀번호가 필요합니다. 서버 PC의 data\access-lock.json 에 해시로만 저장됩니다.
  접속 비밀번호를 잊어버렸을 때: 서버 PC에서 접속비밀번호초기화.bat 을 더블클릭 → Y. 잠금이 풀립니다 (각 PC F5 후 새로 정하기).

6-4. QR(바코드) 접수 (대기 공간에서 환자가 직접)
------------------------------------------
  대기 공간 컴퓨터(또는 태블릿)에 QR(2D) 인식기를 꽂고, 메인 화면에서 "QR 접수"를 고릅니다.
    - 환자가 진료카드 QR을 찍으면 바로 접수되고 "홍*동 (1234)님 접수되었습니다"가 아주 크게 나옵니다
      (저시력 환자도 읽을 수 있게 화면 너비에 맞춘 큰 글씨, 접수 안내는 노란 바탕 검은 글씨).
    - 안내 화면은 5초 뒤 처음 화면으로 돌아갑니다. 노란 접수 안내(처치실 안내 포함)가 있는 환자는 읽을 시간을 더 주도록 8초입니다.
    - 이미 접수한 환자가 다시 찍으면 "홍*동 (1234)님은 이미 접수되었습니다" 아래에 지금 갈 곳을 크게 알려 줍니다.
        시력검사 전                 → 시력검사 대기 중입니다 · 큰 복도에서 기다려 주세요
        검사가 두 곳 이상 남음        → 검사가 남았습니다 · 큰 복도에서 기다려 주세요 (어느 방이 먼저 부를지 그때그때 달라서)
        검사가 한 곳만 남음           → 검사가 한 곳 남았습니다 · ○○로 이동해 주세요 (설정의 '환자에게 보이는 이름')
        처치실이 먼저(초진 검사 지정·진료 전 처치·진료실 요청·예진) → 다음은 처치실입니다 · 처치실로 이동해 주세요
        진료만 남음                  → ○번 진료실에서 진료 예정입니다 · 복도 끝 모니터를 확인해 주세요
          그 교수님 진료 대기 앞 N명 안(또는 진료 호출됨) → 곧 진료 순서입니다 · ○번 진료실 앞으로 이동해 주세요
          (N은 설정 > 기타 '진료실 앞으로 안내할 인원', 기본 5명)
        진료가 끝남                  → 진료가 끝났습니다 · 간호사 안내를 받으시기 바랍니다
      오늘 명단에 없으면 "오늘 예약 명단에서 찾지 못했습니다"가 나옵니다. 시력실은 평소처럼 검사 대기에 뜬 환자를 부르면 됩니다.
    - 처음 연결할 때: 메모장을 열고 바코드를 찍어 환자번호가 그대로 나오고 줄이 바뀌는지 확인하세요.
    - 크롬을 전체 화면(F11)으로 두고, 컴퓨터 절전(화면 꺼짐)을 꺼 두세요.
    - 나가기: 오른쪽 아래 작은 "관리" 글씨 (설정 비밀번호가 있으면 비밀번호를 묻습니다).
    - 잘못 접수되면 시력실 카드의 [접수 취소]를 두 번 눌러 되돌립니다 (한 번 누르면 "누르면 취소", 3초 안에 한 번 더).
  접수 안내: 관리자 > 명단 관리의 환자 카드 [접수 안내 추가]에서 바코드를 찍었을 때 보여줄 문구를 적습니다
    (예: 시력검사 없이 바로 5번 진료실 앞으로 오세요). "시력검사 없이 바로 진료"를 체크하면
    접수하자마자(바코드·직원 접수 모두) 시력/안압을 건너뛰고 진료 대기로 갑니다 (다른 검사가 있으면 검사실로).
    적은 문구는 처음 찍을 때만 나옵니다 (다시 찍으면 위의 '지금 갈 곳' 안내가 나옵니다).
  여러 명에게 한 번에: 명단 관리에서 날짜·교수·오전/오후(필요하면 검색)로 명단을 좁힌 뒤 [접수 안내 일괄 적용]
    → 문구(예: 바로 29번방으로 오세요)와 "시력검사 없이 바로 진료"를 정하고 적용. 접수 전 환자에게만 적용되고,
    바로 [되돌리기]로 취소할 수 있습니다. 한 명만 빼려면 그 환자 카드의 안내 옆 × 를 누르세요.
    예) 교수 "안과특수검사" 선택 → 일괄 적용 / 전체 교수 + 오후 → 일괄 적용 후 몇 명만 ×.

6-5. 환자용 대기 화면 · 안내 문구
------------------------------------------
  환자용 대기 화면 모양 (멀리서도 잘 보이게)
    - 어두운 바탕에 흰 굵은 글씨, 방 색깔은 밝은 색, 안내 문구는 밝은 노란 띠입니다.
    - 맨 위: 제목과 시계. 진료실 화면은 제목 옆에 "5번 진료실"처럼 진찰실 번호가 붙습니다.
    - 직원용 버튼(종 · 자동 스크롤 · 글씨 · 배치 · 메인 화면)은 평소에는 숨겨져 있습니다.
      마우스를 움직이거나 화면을 누르면 오른쪽 아래에 5초 동안 나타납니다. "글씨"를 키워도 이 버튼들은 커지지 않습니다.
      진료실 앞 모니터에서 띵동 소리가 막혀 있으면 오른쪽 아래에 작은 노란 종 그림이 보이니 화면을 한 번 눌러 주세요.
    - 1번 칸은 연한 색 바탕에 모서리 "다음 순서". 검사실 명단은 이름 아래에 갈 검사실 · 검사가 보입니다.
    - 진료실 앞 모니터(환자용 화면 > "OOO 진료실"): 맨 위 "OOO 교수님" + 노란 "N번 진료실"을 크게 한 줄로.
      "다음 순서"가 노란 칸에 가장 크게, 진료 중(이미 진료실 안)은 회색 칸에 조금 작게, 2·3번은 크게 두 칸,
      4번부터는 "그다음 순서" 아래에 작게 보입니다. 진료 중인 환자가 없으면 진료 중 줄은 숨습니다.
    - 시력방 화면: 1번 "다음 순서"는 가장 크게, 2~5번은 크게, 6번부터는 작게.
    - "시력방 + 검사실" 화면(시력방 앞 큰 TV): 화면을 왼쪽 검사실 3 : 오른쪽 시력방 2로 나눕니다.
      시력방은 5명씩 불러 검사하므로 앞 5명을 같은 크기·굵은 글씨로 두 줄로, 6번부터 작게.
      검사실은 이름 아래에 "31번방 시야검사, 안저촬영"처럼 방 이름(방 색깔·굵게)과 할 검사를 한 줄로 크게 보여 줍니다.
      대기 화면 안내 문구는 "시력검사실"·"검사실" 제목 바로 옆에 붙어 나옵니다 (줄 하나를 아껴 명단 자리를 넓게).
    - 검사실마다 따로 된 화면: 환자용 화면 > "정밀검사실 대기 명단"처럼 검사실 이름으로 고르면
      그 검사실에서 할 검사가 남은 환자만 보입니다 (검사실 문 앞 모니터용). 그 검사실 안내 문구만 보입니다.
    - 넓은 모니터는 화면 전체 폭을 씁니다. 명단이 길면 저절로 위아래로 움직입니다 (스크롤 막대는 숨김).
    - 복도 끝 모니터(환자용 화면 > "진료실 대기 명단 (전체)"): 교수님마다 칸을 나누고, 앞 N명은 노란 상자
      "진료실 앞으로 이동해 주세요" 안에 크게, 나머지는 "큰 복도에서 기다려 주세요" 아래에 작게 보입니다.
      N은 설정 > 기타 '진료실 앞으로 안내할 인원'(기본 5명, 0이면 끔).
      직원용 버튼의 [진료실 고르기]로 이 화면에 보일 진료실만 고릅니다 (예: 안과특수검사·처치만 하는 명단은 빼기).
      이 컴퓨터만 기억하고, 체크한 진료실 중 오늘 환자가 있는 곳만 칸이 생깁니다.
    - 환자 찾기: 진료실 화면의 진료 대기 카드 끝 [환자 찾기]를 누르면 복도 끝 모니터에
      "홍*동 (1234)님 / 3번 진료실 앞으로 오세요"가 띵동과 함께 10초 동안 크게 떴다가 사라집니다.
      누른 시각이 버튼 옆에 남고, 여러 명이면 차례로 나옵니다. 그사이 진료 호출·귀가한 환자는 띄우지 않습니다.
      복도 끝 모니터 PC에서 소리가 막혀 있으면(오른쪽 아래 작은 노란 종) 화면을 한 번 눌러 주세요.
  관리자 > "대기 화면 안내"에서 시력방 / 검사실 전체 / 검사실마다 / 교수님(진료실)마다 안내를 적습니다.
    - 검사실 전체: 환자용 화면 검사실 칸 맨 위에 방 이름 없이 보입니다 (예전 고정 문구 "검사 순서는 기계 상황에 따라…"는 없어졌으니 필요하면 여기에 적으세요).
    (예: 예약시간이 빠른 환자부터 먼저 검사합니다, 현재 약 30분 정도 지연되고 있습니다)
    - 칸을 벗어나거나 Enter를 누르면 저장되고, 모든 환자용 화면에 몇 초 안에 노란 띠로 나타납니다.
    - [문구 고르기]로 자주 쓰는 문구를 넣을 수 있고, 목록은 아래 "자주 쓰는 문구"에서 추가·삭제합니다.
    - 적은 문구는 [지우기]를 누를 때까지 계속 보입니다 (다음 날에도 남아 있으니 필요 없으면 지우세요).
  대기 시간 안내 (같은 탭 맨 위): 환자용 화면에 "현재 시력검사 대기 약 N분" / "현재 검사 대기 약 N분"을 띄웁니다.
    - 계산: 시력검사실은 접수 → 시력검사 완료, 검사실은 시력검사 완료 → 첫 검사 완료 시간.
      최근 60분 동안 마친 환자의 중간값과 지금 기다리는 환자의 기다린 시간 중간값 중 큰 값을 5분 단위로 올립니다 (예: 21분 → 약 25분).
      지각 · 2차 진료 · 진료 전 처치 환자는 빼고, 환자가 3명 미만이면 계산하지 않습니다.
    - 검사 시작 시각은 기록되지 않아 "첫 검사 완료"로 계산하므로 첫 검사 시간만큼 조금 길게 나올 수 있습니다.
    - 반자동: [띄우기]를 누르면 그 값이 환자 화면에 나옵니다 (값은 그대로, 오늘만). [지금 값으로 다시 띄우기] / [내리기].
    - 자동: 계산값이 기준(기본 20분) 이상이면 저절로 나오고, 줄어들면 사라집니다. 기준은 아래 "자동일 때 N분 이상"에서 바꿉니다.

6-6. 검사 준비(FAG skin test) · OSDI · 진료 전 처치(PRP·YAG) · History
------------------------------------------
  시간을 재는 검사는 설정 > 검사실 · 검사에서 두 칩 중 하나를 켭니다 (둘은 함께 켤 수 없음):
    [검사 준비] 검사 전에 준비가 필요한 검사 (예: FAG 동의서 · skin test 20분)
      - 처치실 화면 "검사 준비"에 준비 버튼이 나오고, 준비를 [확인]해야 검사실에 그 검사 칸이 열립니다.
      - [자세히]에서 준비 이름(비우면 검사 이름, 예: skin test)과 시간을 정합니다.
    [시간 재기] 검사 자체가 시간을 재는 검사 (예: Schirmer 5분, MMP 10분)
      - 그 검사실 카드의 검사 칸에서 바로 합니다 (처치실이면 "진료 전 검사" 칸, 다른 검사실도 가능).
      - 칸을 누르면 "Schirmer 10:32"처럼 시작 시각 → 시간이 되면 초록 [Schirmer 끝 · 확인] → 검사 완료.
      - [자세히]에서 시간과 방식(①/②)을 정합니다.
    예전 설정에서 처치실 검사에 켜 둔 시간 재기는 자동으로 [시간 재기] 칩으로 옮겨집니다 (따로 할 일 없음).
    시작 전 잘못 눌렀으면 다시 누르면 시작 취소입니다.
    방식 ① 시간이 되면 직원이 [확인]해야 넘어감 (예: FAG skin test, Schirmer)
      - 정한 시간이 되면 버튼이 초록 [… 끝 · 확인]으로 바뀌고 처치실 화면에 알림이 뜹니다.
      - [확인]: 검사 준비는 검사실에 칸이 열리고("확인하면 검사도 완료"를 켜면 검사 완료), 시간 재기는 검사 완료.
      - 처치실 검사(예: Schirmer)는 시간이 되면 처치실 맨 위 "결과 확인"에도 초록 [Schirmer 10:32 · 확인]으로 올라옵니다.
        결과 확인과 진료 전 검사 칸 중 어느 쪽에서 눌러도 같고, 누르면 두 곳에서 함께 빠집니다 (다른 검사실 검사는 그 방 화면에서만).
    방식 ② (시간 재기) 시작하면 바로 넘어가고, 시간이 되면 확인 알림 (예: MMP)
      - 누르면 시작 시각만 기록하고 검사는 완료로 넘어가 환자는 다음 검사·진료로 이동합니다.
      - 처치실 맨 위 "결과 확인"에 남아 있다가, 시간이 되면 초록 [MMP 10:32 · 확인]과 알림이 뜹니다. 결과를 보고 [확인].
    - 시간 전이라도 작은 "지금 확인"을 누르면 바로 완료(확인)됩니다.
    - [진행 중 호출 금지] 칩(예: Schirmer): 시작해 확인하기 전까지 다른 검사실 카드가 "처치실 Schirmer 중 · 호출 금지"로
      잠기고 환자용 화면에도 검사실 대기에서 잠시 빠집니다 (FAG skin test처럼 기다리며 다른 검사를 해도 되면 끄세요).
    - 시간을 재지 않는 검사(예: VF)도 같은 [진행 중 호출 금지] 칩이 있습니다. 켜면 [시작]/[종료] 버튼이 생기고,
      시작~종료 사이에는 다른 검사실에서 부르지 않습니다. VF는 처음부터 켜져 있고, 끄면 보통 검사처럼 [완료]만 누릅니다.
    - 작은 "검사 취소"(반응이 있을 때): 그 검사는 빠지고 진료실 카드에 빨간 "FAG 검사 취소"가 보입니다.
    - 기다리는 동안 다른 검사를 먼저 할 수 있습니다. 확인 전 검사실 카드에는 그 검사 칸이 잠겨 보입니다.
  OSDI처럼 기다리는 동안 할 처치실 검사: 처치실(고정) 칸의 검사에서 [대기 중에도] 칩을 켭니다.
    켜면 다른 검사실 검사를 기다리는 동안에도 처치실 목록에 뜹니다. 끈 검사(예: Syringing)는 다른 검사 뒤에 뜹니다.
  진료 전 처치 (PRP·YAG만 받으러 온 환자): 시력검사 없이 처치실부터 → (검사가 있으면 검사실) → 진료 대기 → 설명.
    - 지정: 설명 완료 창의 [나머지 검사 보기] → "다음 내원 진료 전 처치"에서 고르면 다음 명단에 자동으로 붙고, FU 지정 관리에도 보입니다.
      명단 관리 카드의 [+ 진료 전 처치], 또는 [접수 안내 일괄 적용]의 "진료 전 처치 추가"로도 지정합니다.
    - 처치실 맨 위 "진료 전 처치"에서 [처치 완료]. QR 접수 때는 "시력검사 없이 바로 처치실로 오세요"가 나옵니다.
    - 처치 목록(PRP, YAG 등)은 설정 > 처치에서 추가합니다. "산동 필요"를 켠 처치(예: PRP)는 진료 전 처치로 지정되면
      접수하자마자 산동 예정이 되어 처치실(또는 시력방) 카드의 [산동]으로 바로 점안 시간을 기록할 수 있습니다.
  산동: 산동 예정 환자는 카드에 빨간 [산동] 버튼 하나만 보입니다 (ARK 같은 검사 칸과 같은 방식).
    누르면 "산동 10:32"처럼 점안 시각이 기록됩니다. 시간이 되면 그 버튼이 초록 "산동 완료 10:32"로 바뀝니다 (CR은 "CR 4회 … · 완료").
    잘못 눌렀으면 시각이 찍힌 버튼을 두 번 누릅니다: 한 번 누르면 "누르면 취소"로 바뀌고, 3초 안에 한 번 더 누르면 취소됩니다
    (실수로 한 번 스쳐도 기록이 사라지지 않게).
    CR 환자는 [CR 1회]~[CR 4회]를 차례로 누릅니다.
    지금 완료: 점안 뒤 시간이 되기 전이라도 산동이 이미 충분하면, 시각이 찍힌 점안 버튼(CR은 4회 버튼)을 한 번 누르세요.
      3초 동안 [지금 완료] [누르면 취소] 두 개로 바뀝니다. [지금 완료]를 누르면 바로 산동 완료 (따로 버튼이 늘지 않음).
      잘못 눌렀으면 초록 완료 버튼을 두 번 누르면 확인만 취소됩니다 (점안 기록은 그대로).
  CR·산동 점안 (진료실 간호사 담당): CR 점안은 진료실 화면에서 합니다.
    - 진료실 화면(그 교수님) 진료 대기 바로 위 "CR·산동 점안" 칸에 CR 환자가 접수하자마자 보입니다 (검사 중이어도).
      [1회 점안]~[4회 점안]을 차례로 누르면 시각이 기록됩니다.
    - 마지막 점안 뒤 기다리는 시간(설정의 산동 대기 시간)이 지나면 띵동이 울리고 4회 버튼이 노란 "20분 지남 · 확인"으로 바뀝니다.
      동공을 확인하고 눌러야 진료 대기로 갑니다 (저절로 들어가지 않음). 그 전에 충분하면 4회 버튼 → [지금 완료].
      CR이 끝나기 전에는 진료 대기에 나오지 않습니다. CR을 안 하게 되면 칸 안의 [CR]을 눌러 끄면 바로 진료 대기로 갑니다.
    - 시력방: CR 첫 점안 버튼이 보이지만 누르지 않아도 시력방이 끝납니다 (눌러 둔 점안은 진료실 칸에 이어짐).
    - 처치실: CR 환자는 "CR 2/4 · 진료실"처럼 상태만 보입니다.
  CR·산동 후 다시 진료: 진료 중 [처치] 또는 설명 대기 [처치 보내기] 창 맨 위의 "CR 후 다시 진료" / "산동 후 다시 진료".
    - 고르면 설명 대기로 가지 않고 진료실 "CR·산동 점안" 칸으로 갑니다 ("CR 후 재진" / "산동 후 재진" 표시).
      점안이 끝나고 기다리는 시간이 지나면 점안 버튼이 노란 "N분 지남 · 확인"으로 바뀌고, 눌러야 진료 대기로 돌아옵니다.
      자리는 다른 환자와 같은 규칙: 예약 순서 자리, 예약 순서로 1번이 되면 2번째 (먼저 기다리던 1번은 그대로).
      덜 됐으면 [추가 점안] 뒤 다시 기다렸다가 확인합니다.
    - CR 항목은 설정에서 CR을 켠 교수님만 보입니다. 점안은 1회부터 새로 셉니다 (예전 산동 점안 시각은 기록에 남음).
    - 다른 처치(전공의 처치 등)를 같이 고르면, 다시 진료가 끝난 뒤(진료 완료를 누를 때) 그 처치가 시작됩니다.
    - 다시 진료 환자의 점안 칸에는 점안 버튼만 있습니다. 잘못 보냈으면 카드 끝 작은 글씨 "다시 진료 취소"를 두 번 누르세요.
      원래 있던 곳으로 돌아갑니다 (진료 중에 보냈으면 진료 대기 맨 앞, 설명 대기에서 보냈으면 설명 대기 원래 순서).
      산동·점안 기록도 보내기 전으로 돌아갑니다. 다른 화면에서 산동·CR을 끄면 "재진" 표시도 사라집니다.
    - 다시 진료를 마친 뒤 [진료 완료 취소]를 누르면, 같이 골라 둔 처치도 다시 "다시 진료 뒤 처치"로 돌아갑니다.
    - 잘못 눌렀으면 아래 알림의 [되돌리기].
    추가 점안: "산동 완료"(또는 노란 "N분 지남 · 확인")가 됐는데 덜 됐으면 옆의 작은 "추가 점안"을 누릅니다 (CR 환자 제외).
      - 버튼이 "산동 11:05 · 2회"처럼 마지막 점안 시각과 횟수로 바뀌고, 그 시각부터 다시 시간을 잽니다.
      - 잘못 눌렀으면 그 버튼을 누르면 추가 점안만 취소됩니다 (처음 점안 기록은 그대로).
      - 산동 금지 검사(VF 등)가 남아 있으면 "추가 점안"이 보이지 않습니다.
    산동 예정을 넣거나 빼는 것은 다른 검사처럼 [+ 검사 변경]을 펼쳐 [산동] / [산동 안 함]으로 합니다(CR도 같음).
    VF처럼 "산동 금지" 검사가 남아 있으면 "산동 · VF 끝난 뒤"로 잠겨 기록할 수 없고, 그 검사를 마치면 [산동] 버튼이 나옵니다.
  검사 옵션(설정 > 검사실 · 검사): 검사 이름 아래의 작은 칩을 눌러 켜고 끕니다(켜진 칩은 색이 채워짐).
    칩에 마우스를 올리면 설명이 나오고, 전체 설명은 위쪽 "도움말 · 검사 옵션 설명"을 누르면 한 번에 볼 수 있습니다.
    검사는 한 줄씩 보이고, 검사 이름이나 [자세히]를 누르면 이름·검사실·세부 종류·삭제 칸이 펼쳐집니다.
    - 세부 창: 누를 때마다 단안·프로토콜 등 세부 창 띄우기
    - 처방 없음: 처방이 필요 없는 검사(예: OSDI) - "처방 전" 표시가 나오지 않음
    - 산동 금지: 이 검사를 마치기 전에는 점안(산동)을 기록할 수 없음 (VF는 처음부터 켜져 있음)
    - 검사 준비: 검사 전 준비(예: FAG skin test)를 처치실 "검사 준비"에서 시간 재고 [확인]해야 검사 가능
    - 시간 재기: 검사 칸에서 시작 시각 기록 → 정한 시간이 되면 [확인] (예: Schirmer, MMP · 방식은 [자세히]에서 선택)
    - 대기 중에도: (처치실) 검사실 대기 중에도 바로 하기
    - 진행 중 호출 금지: 그 검사를 하는 동안 다른 검사실에서 부르지 않음 (예: Schirmer, VF · VF는 기본으로 켜짐)
    - 0명도 표시: 대기 0명이어도 위쪽 장비 목록에 보이기 (장비가 2대 이상일 때)
  시력방 검사: 설정 > 검사실 · 검사 맨 위 시력방 칸에서 ARK 같은 검사를 추가·수정·삭제할 수 있습니다.
    지정된 시력방 검사를 모두 마쳐야 시력/안압 단계가 끝납니다.
  시력방 할 일이 모두 끝나면 자동으로 다음 단계로 넘어갑니다 ("○○ 시력방 완료" 알림, [되돌리기] 가능).
    할 일: [시력] · [NCT] · (초진) [History 설문지 드리기] · 시력방 검사(ARK 등) · (산동 예정) [산동] 점안.
    - [시력]과 [NCT]는 따로 누릅니다. 누르면 그 칸만 적는 창이 열리고, [확인]하면 초록 "✓ 시력" / "✓ NCT"로 바뀝니다.
      둘 다 끝나면 측정 완료 (버튼이 사라지고 "오늘 …" 줄 끝 [수정]으로 고칩니다).
    - NCT를 재지 않는 환자는 [NCT] 자리에 노란 "NCT 안 함 · 검사실 GAT"(GAT 지정) 또는 "안압 안 잼"(소아 등)이 보이고,
      [시력]만 하면 됩니다. 노란 표시를 누르면 안압 창에서 "GAT로 측정" / "안압 안 잼"을 바꿀 수 있습니다.
    - 안압을 아예 안 재는 환자(소아 등)는 관리자 > 명단 관리 [초진/재진] 옆 [안압 잼]을 눌러 [안압 안 잼]으로 미리 정할 수 있습니다.
    - 지금 점안할 수 없으면 [산동] 옆 "점안 없이 넘기기" (산동 예정은 그대로라 다음 검사실·처치실에서 기록).
    - VF처럼 산동 금지 검사가 남은 환자는 점안 없이 넘어갑니다.
    - 되돌리면 측정 완료가 풀려 시력방으로 돌아옵니다 (입력한 값은 그대로).
  시력방 카드: 맨 위에 이전 시력(파란 칸, 큰 글씨)과 이전 안압(회색 칸). 시력이 좋던 환자는 작은 글씨부터 바로 재세요.
    입력 창에도 이전 값이 같은 OD·OS 세로줄에 크게 보입니다.
    아래 줄: [시력] [NCT] [History 설문지 드리기](초진만) [산동] "오늘 검사 N 보기" ... [접수 취소].
    "오늘 검사 N 보기"를 누르면 오늘 검사(검사실 검사 포함)가 펼쳐지고 그 자리에서 바꿀 수 있습니다 (평소엔 접혀 있음).
    이름 옆 [초진]/[재진]을 누르면 서로 바뀝니다 (초진이어도 ARK는 자동으로 지정되지 않음).
    CR은 켜져 있을 때만 [CR]이 보이고, 켜고 끄기는 "오늘 검사 보기" 안에서 합니다.
  History: 시력방은 초진 환자에게 설문지만 드리고 [History 설문지 드리기]를 누릅니다 (누르기 전에는 시력방이 끝나지 않음).
    입력은 처치실에서 설문지를 보고 합니다.
    - 처치실 "검사 지정 대기"·"예진 대기" 카드의 주황 [History 입력]을 눌러 고혈압·당뇨(유병기간)·기타 과거력·
      안과 수술력(줄글)·주호소를 적고 [확인]. 입력하면 카드에 내용이 보이고 [수정]으로 고칩니다.
    - 입력하지 않아도 [검사 지정]은 할 수 있습니다 (막지 않음). 진료실에서는 "History 미입력"으로 보입니다.
    - 초진이면 History 필요, 재진은 필요 없습니다. FU가 길어져 초진으로 올라온 환자는 이름 옆 [초진]을 눌러 재진으로,
      FU loss·중간 내원처럼 재진인데 History가 필요하면 [재진]을 눌러 초진으로 바꿉니다.
    - 항목은 설정 > 기타 > "History 양식"에서 추가·삭제·순서·형식(있음/없음, 기간, 한 줄, 여러 줄)을 바꿀 수 있습니다.
    - 적은 내용은 진료실 카드에 한 줄로 보입니다. History는 초진 때만 쓰므로 그날 기록에만 저장되고 다음 내원 때 불러오지 않습니다.
  검사 결과 입력 (MR · WG 등): 설정 > 검사실 · 검사에서 검사를 추가하고 [결과 입력]을 켜면, 옆에 S · C · A · Add · VA 칸 버튼이 생깁니다.
    필요한 칸만 남기세요 (예: MR은 5칸 모두, 기존 안경 도수 WG는 S · C · A만).
    - 검사실에서 그 검사 칸을 누르면 결과 창(R · L 두 줄)이 열리고 [MR 완료]로 저장 + 완료됩니다.
    - 검사실 카드에 결과가 한 줄로 보이고 [수정]으로 고칩니다. 진료실(진료 중)에는 시력·안압 표 아래에 MR 표가 보입니다.
    - 결과는 그날만 보입니다 (다음 내원 때 이전 값으로 나오지 않음, 그날 명단 기록에는 남음).
  오늘 검사 목록: NCT를 잰 환자는 처치실·진료실·설명 대기의 "오늘 검사"에 NCT도 함께 보입니다.

7. 같은 날 두 교수님 진료 (2차 진료)
------------------------------------------
  교수님마다 진료 기록이 따로 있고, 2차 진료는 1차 진료의 "설명 완료" 뒤에 시작합니다.
  2차 진료는 그 전까지 직원 화면에 보이지 않고, 관리자·전체 환자 명단에서
  "OOO 진료 후 대기 (2차 진료)"로 보입니다.

  (1) 미리 예정된 경우: 두 교수님 명단에 모두 올리면 자동으로 연결됩니다.
      - 예약시간이 빠른 교수님이 1차. 명단 관리의 [진료 순서 바꾸기]로 바꿀 수 있습니다 (접수 전까지).
      - 두 교수님의 검사를 1차 진료 전에 한 번에 합니다.
  (2) 진료 중에 추가하는 경우: 진료실 [설명 완료] 창 → [나머지 검사 보기] →
      "오늘 다른 교수 진료 추가"에서 교수님을 고르고 설명 완료를 누릅니다.
      (관리자 > 환자 추가에서 다른 교수님으로 추가해도 됩니다)
      - 설명 완료 후 처치실 "검사 지정 대기"에 [추가 검사 확인]으로 올라옵니다.
        추가할 검사를 고르면 검사실로, 없으면 바로 2차 교수님 진료 대기로 갑니다.

  설정 > 기타 에서 처치실 확인을 거칠지 정할 수 있습니다.
     진료 중에 추가된 2차 진료 → 처치실 확인 (기본: 켬)
     미리 예정된 2차 진료     → 처치실 확인 (기본: 끔)


  메인 화면: "진료 흐름 · 직원 화면"(시력방·검사실·처치실·진료실) / "환자용"(환자용 화면·QR 접수) /
    "관리"(관리자·설정·전체 환자 명단) 세 묶음입니다.
    - 맨 아래 버전 글씨 옆 하트 버튼 [감사의 글]: 이 프로그램을 만든 사람의 인사말입니다 (예전 설정 > 기타의 개발자 정보는 여기로 옮김).
    - 직원 화면 칸 아래에 "N 명 대기"가 큰 숫자로 보입니다 (그 화면 위쪽 "대기 N명"과 같은 숫자).
      진료실 칸 아래에는 교수님별 인원도 보입니다 (오늘 명단에 환자가 없는 교수님은 빠짐).
  띵동 알림: 직원이 컴퓨터 앞에 없어도 새 일이 생기면 그 화면을 띄운 컴퓨터에서 "띵동" 소리가 납니다.
    - 시력방: 새 환자 접수(QR 접수·직원 접수 모두, 진료실에서 시력/안압 다시 보낸 환자 포함)
    - 검사실: 묶음 안 어느 검사실이든 대기 명단에 새 환자 (31번방 화면에서도 6번방 새 환자에 울림)
    - 처치실: 어느 묶음이든 새 환자, 또는 시간 재기·검사 준비·결과 확인의 "시간 됨"
    - 진료실: 그 교수님 진료실에 진료 호출 (진료실 앞 컴퓨터 등에서 듣는 용도)
    - 환자용 진료실 화면(교수님 한 분)에서도 같은 진료 호출에 띵동이 납니다. 오른쪽 아래 작은 종 버튼으로 그 컴퓨터만 끄고 켭니다.
      모니터를 켠 뒤(F5 포함) 화면을 한 번도 누르지 않으면 크롬이 소리를 막으니, 켜 둘 때 화면을 한 번 눌러 주세요.
    - 그 컴퓨터에서 방금(2초 안) 직접 누른 변화는 소리를 내지 않습니다. 메인 화면에서는 소리가 나지 않습니다.
    - 화면 위쪽 종 모양 버튼으로 그 컴퓨터만 소리를 끄고 켭니다 (컴퓨터마다 기억).
    - 크롬은 화면을 한 번도 누르지 않으면 소리를 막습니다. 그럴 때는 위쪽에 "소리를 켜려면 화면을 한 번 눌러 주세요"가 보이니
      화면을 한 번 누르세요. (메인 화면에서 자기 화면을 누르고 들어가면 보통 바로 켜져 있습니다)
    - 스피커가 연결되어 있고 컴퓨터 소리가 꺼져 있지 않은지 확인하세요.
    - 태블릿(갤럭시탭): 화면을 한 번 누르면(손을 떼는 순간) 소리가 켜집니다. 소리가 안 나면
      ① 볼륨 버튼을 눌러 "미디어" 음량을 올리세요 (알림 음량과 따로입니다).
      ② 태블릿 화면이 꺼지거나 다른 앱으로 넘어가면 웹 화면이 멈춰 소리가 나지 않습니다.
         설정 > 디스플레이 > 화면 자동 꺼짐 시간을 길게 하세요.
         충전기에 꽂아 두고 쓰면: 개발자 옵션 > "화면 켜짐 상태로 유지"를 켜면 꺼지지 않습니다.
         (개발자 옵션 켜기: 설정 > 태블릿 정보 > 소프트웨어 정보 > 빌드번호를 7번 누르기)
  전체 환자 명단: 환자 한 명이 한 줄로, 지금 어디서 무엇을 기다리는지 보입니다. [메인 화면]으로 나갑니다.
    상태 칸은 방 색깔입니다 (시력방 파랑 · 검사실은 방마다 색 · 처치실 남색 · 진료실 주황).
  관리자 > 오늘 통계: 명단·접수·귀가 인원, 단계별 평균 시간(시력방·검사·진료 대기·진료·설명·전체),
    교수별 표, 시간대별 접수 인원. 날짜를 바꾸면 지난 날도 볼 수 있습니다.
    (진료 대기·진료 시간은 [진료 호출] 시각으로 계산하며, 이 기능이 생긴 뒤 진료한 환자부터 계산됩니다)
  관리자 > 역할별 안내문: 시력방·검사실·처치실·진료실·관리자 1장 요약. [인쇄]하면 역할마다 한 장씩 나옵니다.
  이전 시력 기록: 모든 컴퓨터는 명단(오늘 + 앞으로 올린 날짜)에 있는 환자 것만 받아 빠르게 동작합니다.
    환자마다 오늘과 지난 1회만 보관하고, 저장할 때도 그 환자 칸만 주고받아(서버에서는 100개로 나눈 파일 중 하나만 씀) 환자 수가 쌓여도 느려지지 않습니다.
    (매 내원의 측정값은 그날 명단 기록과 월별 보관 파일에 모두 남아 있습니다.)
    다음 주 명단을 미리 올려 두면 차트리뷰 때 지난 시력·예정 검사가 보이고, [이전 시력 입력]도 그대로 됩니다.
    옛 기록은 서버에 그대로 남아 있어 그 환자가 명단에 오르면 다시 보입니다.

  설정 > 교수 관리는 다른 탭처럼 고친 뒤 아래 [저장]을 눌러야 적용됩니다.
  교수님별 주요 검사: 설정 > 교수 관리의 "주요 검사"에서 체크한 검사만 먼저 보이고, 나머지는 [기타 검사]를
    눌러야 보입니다. [검사 변경](시력방·검사실·관리자 명단), 처치실 [검사 지정]·진료실 [추가 검사] 창, 설명 완료 창에 모두 적용.
    이미 지정된 검사는 항상 보이고, 목록을 정하지 않은 교수님은 모든 검사가 그대로 보입니다.

8. 문제 해결
------------------------------------------
  - "3000번 포트를 이미 사용 중" / "이미 켜져 있습니다" : 서버가 이미 창 없이 켜져 있습니다. 서버상태확인.bat 으로 확인하세요.
  - 창 없이 켜기가 실패할 때      : 서버시작.bat 으로 켜서 검은 창의 오류 메시지를 확인하세요.
  - 다른 PC에서 접속이 안 됨      : 서버 PC 주소가 맞는지, 방화벽 허용(1-(4))을 했는지 확인하세요.
                                    서버 PC 자신에서는 http://localhost:3000 으로 열리는지 먼저 확인하세요.
  - 서버 PC 주소가 가끔 바뀜      : 전산실에 서버 PC의 IP 고정을 요청하세요.
  - "Node.js 가 설치되어 있지 않습니다" : 1-(1)을 다시 확인하세요. 설치 후 컴퓨터를 재시작하면 해결되는 경우가 많습니다.
  - 태블릿에서 띵동이 안 남       : 화면을 한 번 누르고, 미디어 음량과 화면 자동 꺼짐 시간을 확인하세요 (띵동 알림 설명 참고).
  - "저장 실패" 빨간 띠가 자주 뜸  : 서버상태확인.bat 으로 서버를 확인하고, data\server-log.txt 의 [오류] 줄을 확인하세요.
  - 명단·FU를 예전 시점으로       : 백업복구.bat (4번 복구 방법).
  - "화면을 그리는 중 오류" 안내   : [다시 시도]. 계속 반복되면 data\server-log.txt 의 [화면 오류] 줄을 개발 담당에게 알려 주세요.
