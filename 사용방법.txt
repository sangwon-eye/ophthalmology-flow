안과 환자 흐름 - 내부망 공유 사용 방법
==========================================

[구조]
  컴퓨터 한 대를 "서버 PC"로 정합니다. 앱과 데이터는 서버 PC에만 있습니다.
  다른 컴퓨터(접수, 검사실, 진료실, 처치실 등)는 아무것도 설치하지 않고
  브라우저(크롬 또는 엣지) 주소창에 서버 PC 주소만 입력하면 됩니다.

  서버 PC 고르는 법: 근무 시간 내내 켜져 있는 컴퓨터로 정하세요.
  서버 PC가 꺼지면 다른 컴퓨터에서도 사용할 수 없습니다.


------------------------------------------
1. 서버 PC 처음 설정 (한 번만)
------------------------------------------
 (1) Node.js 설치
     https://nodejs.org 에서 LTS 버전(22.12 이상)을 받아 설치합니다.
     서버 PC에 인터넷이 안 되면, 인터넷 되는 PC에서 설치 파일(.msi)을 받아
     USB나 공유폴더로 옮겨서 설치하세요.

 (2) 이 폴더를 서버 PC의 내 컴퓨터(예: C:\안과흐름)에 복사합니다.
     ※ 공유폴더(네트워크 드라이브) 안에서 실행하지 마세요. 느리고 오류가 날 수 있습니다.

 (3) 서버시작.bat 을 더블클릭합니다.
     검은 창에 아래처럼 주소가 나오면 성공입니다.
        다른 컴퓨터에서 접속: http://192.168.0.15:3000   ← 예시입니다
     이 주소를 메모해두세요.

 (4) 처음 실행할 때 "Windows 보안 경고(방화벽)" 창이 뜨면
     "개인 네트워크"(병원 네트워크면 "도메인 네트워크"도)에 체크하고 [액세스 허용]을 누릅니다.
     관리자 권한이 없어 허용하지 못하면 전산실에
     "3000번 포트(TCP) 내부망 접속 허용"을 요청하세요.


------------------------------------------
2. 매일 사용
------------------------------------------
  서버 PC : 서버시작.bat 더블클릭 → 검은 창을 닫지 말고 최소화해 둡니다.
  다른 PC : 브라우저에서 http://서버PC주소:3000 접속
            (즐겨찾기나 바탕화면 바로가기로 만들어두면 편합니다)

  화면 맨 위에 빨간 줄로 "서버 PC에 연결되지 않았습니다"가 나오면
  서버 PC가 켜져 있는지, 검은 창이 열려 있는지 확인하세요.
  연결되지 않은 동안 입력한 내용은 저장되지 않습니다.

  서버 PC가 켜질 때 자동으로 서버도 켜지게 하려면:
    Windows키 + R → shell:startup 입력 → 열린 폴더에
    서버시작.bat 의 "바로 가기"를 넣어두세요 (파일 자체가 아니라 바로 가기).


------------------------------------------
3. 코드를 수정했을 때 (업데이트)
------------------------------------------
  (1) 서버 PC의 src\App.jsx 를 수정합니다.
  (2) 업데이트.bat 을 더블클릭합니다. (처음 한 번은 인터넷 연결이 필요합니다)
  (3) 끝나면 각 컴퓨터 화면 위에 "새 버전이 있습니다" 알림이 뜹니다.
      [새로고침]을 누르면 적용됩니다. 서버를 다시 켤 필요는 없습니다.

  ※ 환자가 많은 시간에는 업데이트를 피하세요 (몇 초 동안 화면이 안 열릴 수 있습니다).
  ※ 업데이트 중 오류가 나면 서버는 이전 버전 그대로 계속 동작합니다.
  ※ server.js 를 수정한 경우에만 서버 창을 닫고 서버시작.bat 을 다시 실행하세요.
  ※ 다른 PC에서 수정했다면 수정한 파일(src 폴더)을 서버 PC 폴더에 덮어쓴 뒤 업데이트.bat 을 실행하세요.


------------------------------------------
4. 데이터와 백업
------------------------------------------
  데이터 파일 : data\store.json  (서버 PC에만 있습니다)
  자동 백업   : data\backups\store-날짜.json  (하루 한 번, 최근 30일 보관)

  공유폴더에도 백업하려면 서버시작.bat 을 메모장으로 열어
     rem set BACKUP_DIR=\\공유PC이름\공유폴더\안과백업
  줄 맨 앞의 "rem " 을 지우고 경로를 실제 공유폴더로 바꾸세요.

  복구 방법: 서버 창을 닫고 → 백업 파일을 data\store.json 이름으로 복사해 덮어쓰고 →
            서버시작.bat 을 다시 실행합니다.

  폴더를 다른 서버 PC로 옮길 때는 data 폴더도 같이 복사하세요.


------------------------------------------
5. 여러 컴퓨터가 동시에 입력하면?
------------------------------------------
  두 컴퓨터가 같은 순간에 저장해도, 늦게 저장한 쪽이 최신 내용을 다시 불러와서
  자기 변경을 다시 적용합니다. 그래서 한쪽 입력이 사라지지 않습니다.
  다른 컴퓨터의 변경은 4초 안에 화면에 반영됩니다.


------------------------------------------
6. 문제 해결
------------------------------------------
  - "3000번 포트를 이미 사용 중" : 서버가 이미 켜져 있습니다. 작업표시줄의 검은 창을 확인하세요.
  - 다른 PC에서 접속이 안 됨      : 서버 PC 주소가 맞는지, 방화벽 허용(1-(4))을 했는지 확인하세요.
                                    서버 PC 자신에서는 http://localhost:3000 으로 열리는지 먼저 확인하세요.
  - 서버 PC 주소가 가끔 바뀜      : 전산실에 서버 PC의 IP 고정을 요청하세요.
  - "Node.js 가 설치되어 있지 않습니다" : 1-(1)을 다시 확인하세요. 설치 후 컴퓨터를 재시작하면 해결되는 경우가 많습니다.


------------------------------------------
(참고) 개발용 실행 - 코드를 고치면서 바로 확인하고 싶을 때
------------------------------------------
  PowerShell 창 두 개를 열고, 각각 아래를 실행합니다.
     창 1:  npm.cmd start
     창 2:  npm.cmd run dev
  브라우저가 http://localhost:5173 으로 열리고, 저장하면 화면이 바로 바뀝니다.
  이때도 데이터는 같은 data\store.json 을 사용합니다.
